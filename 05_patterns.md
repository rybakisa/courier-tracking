# Артефакт 5. Архитектурные паттерны

> **Раздел в работе.** Будет наполнен на следующем шаге проектирования.

Здесь будут описаны применённые архитектурные паттерны и обоснование их выбора:

- Разделение горячего и холодного пути (CQRS-подобное разделение чтения и записи).
- Лог-ориентированный ingestion (event log класса Kafka).
- Геопространственное индексирование (geohash / S2 / H3).
- Серверная кластеризация для плотных диспетчерских вьюпортов.
- Pub/Sub fan-out для real-time доставки обновлений.
