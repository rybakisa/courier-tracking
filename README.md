# Система трекинга курьеров — системный дизайн

Учебный проект по системному дизайну, оформленный как сайт-документация на Next.js.
Проектируемая система — международный real-time сервис трекинга курьеров на карте.

Семь артефактов проектирования лежат в корне репозитория как Markdown и рендерятся сайтом:

| 06 | Масштабируемость        | `06_scalability.md`   | В работе |
| 07 | Мониторинг              | `07_monitoring.md`    | В работе |

## Стек

Next.js (App Router), React, TypeScript. Markdown рендерится через `marked`.
Контент статический — весь сайт пререндерится при сборке.

## Запуск локально

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # продакшен-сборка
```

## Деплой на Vercel через GitHub

1. Создай пустой репозиторий на GitHub.
2. Запушь проект (git-репозиторий уже инициализирован, первый коммит сделан):
   ```bash
   git remote add origin https://github.com/<user>/<repo>.git
   git branch -M main
   git push -u origin main
   ```
3. Зайди на [vercel.com](https://vercel.com) → **Add New → Project** → импортируй репозиторий.
4. Vercel автоматически определит Next.js. Нажми **Deploy** — настройки менять не нужно.

Каждый следующий `git push` в `main` будет деплоиться автоматически.

## Структура

```
app/                   — страницы (App Router)
  layout.tsx           — общий каркас: шапка и подвал
  page.tsx             — главная: обзор задачи + карточки артефактов
  artifacts/[slug]/    — страница артефакта (рендер Markdown)
  globals.css          — стили
lib/artifacts.ts       — метаданные артефактов и загрузка Markdown
0X_*.md                — контент артефактов
```
