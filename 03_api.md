# Артефакт 3. API

> **Раздел в работе.** Будет наполнен на следующем шаге проектирования.

Здесь будут описаны контракты API системы. Планируемый охват — четыре группы контрактов,
по одной на каждый поток данных:

- **Приём пинга от курьера** — эндпоинт/стрим записи геопозиции.
- **Подписка клиента** — слежение за одним конкретным курьером в реальном времени.
- **Запрос диспетчера по области** — bbox-запрос плюс подписка на обновления внутри вьюпорта.
- **Чтение истории** — маршрут за сегодня и за произвольный период.

Для каждого контракта будут указаны протокол (HTTP / WebSocket / gRPC), формат запроса
и ответа, коды ошибок и семантика идемпотентности.
